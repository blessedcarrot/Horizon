## [Compiler Converts Computation Graphs to Transformer Weights Without Training](https://www.reddit.com/r/MachineLearning/comments/1v5fxbe/i_built_a_compiler_that_turns_computation_graphs/) ⭐️ 8.0/10

A new compiler, TorchWright, converts arbitrary computation graphs defined in ordinary Python into the weights of a vanilla transformer \(specifically Phi-3 architecture\) with no training, producing a standard HuggingFace checkpoint that loads without custom code. This work bridges the gap between programmatic specification and transformer execution, enabling interpretability researchers to build and analyze transformer models that implement known algorithms without relying on learning. It also makes compiled transformers accessible to the wider community by targeting a stock architecture and standard HuggingFace loading. The compiler produces weights for a Phi-3-architecture transformer, a standard decoder-only model. The repository includes twelve runnable examples, and the write-up explains the construction mechanisms.

reddit · r/MachineLearning · /u/notforrob · Jul 24, 16:15

**Background**: Transformers are neural networks that process sequences using attention and feed-forward layers. RASP is a programming language designed to express transformer computations, and Tracr is a prior compiler that translates RASP programs into transformer weights. This new compiler extends these ideas by allowing computation graphs written in ordinary Python and targeting a stock transformer architecture without custom code, unlike Tracr which requires specific model tweaks.

GDDR7 is the latest graphics memory standard succeeding GDDR6, offering higher bandwidth but currently commanding premium prices. Nvidia&\#x27;s Blackwell architecture powers the high-end RTX 50 series, while the GeForce line uses GDDR6 memory.
