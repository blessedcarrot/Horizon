# Practice profile

Use this profile for developments an engineering team could act on within a quarter: inference and serving techniques, agent reliability and orchestration, evaluation methods that change a decision, developer tooling, local and open-weight model behaviour, cost and performance techniques, production incidents and postmortems, and hard-won operational experience.

Typical items include a production trace that changes how you size infrastructure, a finding about what actually makes coding agents reliable, a tool or model release with real deployment consequences, or a benchmark result that should change what you build on.

Do not use this profile for research whose applicability is still unproven, that is Horizon. Do not use it for commercial news, or for safety and security findings, which have their own profiles. Do not use it for beginner tutorials or content that restates documentation.
